HOTEL MANAGEMENT SYSTEM

Objective / Problem Statement

  • The task is to develop a Hotel Management System that handles various aspects of hotel operations, including room check-in, check-out, food orders, and maintenance management. The system should allow the hotel staff to manage guest information, order food for guests, check room availability, and perform maintenance tasks. Additionally, the system should be able to save and load room data to and from a file for persistence.

    • What I Did

  • Room Management: The system allows rooms to be checked in and checked out, keeping track of the guest name and room status (occupied or not)
  • Food Ordering: Guests can place food orders for breakfast, lunch, snacks, and dinner. The system keeps track of these orders
  • Room Maintenance: Maintenance tasks can be performed on rooms that are not occupied.
  • Persistent Data Storage: The system saves and loads room data, including guest information, room status, and food orders, from a file (hotelData.txt).

    • Tools Used

  • Java Programming Language: For developing the entire hotel management system
  • Swing (Java GUI):To create the graphical user interface for interacting with the system.
  • BufferedReader & BufferedWriter: For reading from and writing to the file to persist room data.
  • JOptionPane: For displaying dialogs to gather user input, such as room number and guest name.
  • ArrayList: To store room data in memory for easy access and modification

    • Key Features:

  • Room Check-in and Check-out: Allows guests to check into available rooms and check out when their stay is over.
  • Food Ordering: Guests can order food for breakfast, lunch, snacks, and dinner, and their orders are stored in the system.
  • Maintenance Management: The system can mark rooms as under maintenance, ensuring they are not assigned to guests during this time
  • Availability Display: A function to display rooms that are available for booking and not under maintenance.
  • Persistent Data Storage: All room data, including guest names, food orders, and maintenance status, is saved to a file and can be reloaded when the system is restarted

    • Project Implementation:

  • Room Class: Manages room information such as room number, guest name, occupancy status, maintenance status, and food orders.
  • FoodOrder Class: Represents the food orders placed by guests, including breakfast, lunch, snacks, and dinner.
  • HotelManagementSystem Class: The main class that runs the hotel system, providing the GUI and functionality for interacting with rooms, guests, and orders. It includes event listeners for handling user actions such as check-in, check-out, food ordering, and maintenance.
  • File Operations: The system reads and writes room data to a text file (hotelData.txt) to maintain persistent information across multiple sessions.

    • Conclusion

    The Hotel Management System is a comprehensive application that simplifies hotel operations. It provides a user-friendly interface for managing room bookings, food orders, and room maintenance. The system also ensures data persistence through file storage, making it robust for real-world usage. Future enhancements could include adding features like room pricing, billing, and customer feedback. Overall, the system efficiently meets the requirements of hotel management and offers a scalable solution for managing guest and room information.
