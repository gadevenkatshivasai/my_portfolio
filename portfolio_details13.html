VECHILE NUMBER DETECTION

Objective / Problem Statement

  • The aim of this project is to develop a system that automatically detects and recognizes vehicle number plates from images using image processing and OCR techniques. The core problem addressed is the manual and time-consuming process of identifying vehicle registration numbers, especially in traffic monitoring, parking systems, and surveillance applications..

    • What I Did

  • Built a Python-based application using OpenCV and Tesseract OCR.
  • Processed real-world vehicle images to detect and extract number plates.
  • Applied edge detection and contour-based masking to isolate the plate region.
  • Used Optical Character Recognition (OCR) to extract text from the detected plates.
  • Visualized each step using Matplotlib to ensure transparency and easy debugging

    • Tools Used

  • Language: PYTHON
  • Libraries: OpenCV, Pytesseract, Matplotlib, NumPy
  • OCR Engine: Tesseract OCR
  • Platform: Windows, portable for linux

    • Project Implementation:

  • Imported all necessary packages and configured Tesseract path.
  • Loaded and resized the input image.
  • Converted to grayscale and applied bilateral filtering.
  • Used Canny edge detection and located contours.
  • Filtered rectangular contours most likely to be plates
  • Created a mask and cropped the region of interest.
  • Applied pytesseract for extracting characters.
  • Displayed results including intermediate processing stages.

    • Functionality

  • Accepts input image of a vehicle.
  • Processes and isolates the number plate area
  • Extracts text from the plate using OCR.
  • Displays detected number and processing visuals.

    • Deployment

  • Can be deployed as a desktop application using Python GUI libraries.
  • Easily extensible to real-time applications using a webcam or IP camera
  • Can be containerized using Docker for cloud deployment or API integration.
  • Lightweight enough for Raspberry Pi or edge devices for smart surveillance.

    • Conclusion

    This project successfully demonstrates the automation of number plate detection and recognition using computer vision and OCR. It offers a foundation for building smart traffic systems and vehicle monitoring solutions. The solution is efficient, scalable, and can be integrated into larger surveillance systems or embedded platforms.
