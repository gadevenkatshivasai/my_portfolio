NUMBER GUESSING

Objective / Problem Statement

  • The objective of this project is to create an interactive Number Guessing Game that tests the player's ability to guess a randomly generated number within a limited number of attempts. The problem is designed to improve logical thinking, user input handling, and basic programming skills in Java

    • What I Did

  • Logical Thinking: Understanding of loops, conditional statements, and random number generation.

    • Tool

    • Programming Language: Java
    • IDE/Compiler: Any Java-compatible IDE such as IntelliJ IDEA, Eclipse, or BlueJ.
    • JDK: Java Development Kit for compiling and running the program.
    • Input/ Output Scanner class for user input and System.out for console output.

    Outcome

    The Number Guessing Game successfully achieves its objective of providing an interactive and engaging experience for the user. Players can test their guessing skills while receiving helpful hints to improve their chances. The project demonstrates a clear understanding of Java fundamentals, including:

  • Random number generation.
  • Conditional logic for decision-making.
  • Iterative loops for managing attempts.
  • User input handling through the Scanner class.

    • Key Features

    • Random Number Generation A number between 1 and 100 is randomly generated.
    • Limited Attempts: The player has 5 trials to guess the correct number.
    • Hints for Assistance: If the guess is incorrect, the program provides a hint indicating whether the number is greater or smaller than the guess.
    • Winning and Losing Conditions: If the player guesses the number correctly, a congratulatory message is displayed.
    • If the player fails to guess the number within the given trials, the correct number is revealed.
    • User-Friendly Interface: The game uses clear prompts to guide the player.

    Project Implemetation

    • Random Number Generation: The number is generated using the formula int number = 1 + (int)(100 * Math.random());
    • Input Handling: User input is read using the Scanner class.
    • Logic: A for loop iterates up to 5 times (5 guesses allowed.
    • Conditional statements (if, else if) are used to compare the guessed number with the actual number.

    Result

    • Appropriate messages are displayed for success, failure, and hints.

    Conclusion

    This Number Guessing Game project demonstrates the use of core Java concepts like loops, conditionals, random number generation, and user input. It serves as a beginner-friendly project that enhances problem-solving skills and understanding of Java programming fundamentals. The project is simple yet engaging, making it an excellent addition to a programming portfolio.
